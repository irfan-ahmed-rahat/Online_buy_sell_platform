# Online Buy & Sell Marketplace 🛒

A dynamic classified advertisement and marketplace platform where users can easily list items, browse various categories, and connect with potential buyers and sellers. 

# Project Demo
[Click here to watch the full Video Walkthrough on YouTube](#)

# Key Features 
User Authentication : Secure login and registration for buyers and sellers.
Custom Ad Posting : Users can post, edit, and manage their product listings effortlessly.
Advanced Search & Filters : Filter products by category, price range, and custom location tags.
Admin Dashboard : Centralized control for managing users, categories, and active advertisements.
